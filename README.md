# 刈谷市 学校マップ（JAC-Academy追加版）

GitHub Pages用の静的Webマップです。

## ファイル
- `index.html`：地図・検索・フィルター・町境表示
- `schools.js`：学校27校＋JAC-Academyの名称・住所・座標・偏差値
- `.nojekyll`：GitHub Pagesで静的ファイルをそのまま配信するためのファイル

## JAC-Academy
JAC-Academy総合学院を学校とは別カテゴリとして追加しています。
- 赤い専用ピン（JAC表記）
- 「🔴 JAC」フィルター
- 一覧からタップして赤ピンへ移動
- ポップアップに住所と公式サイトへのリンクを表示

住所：愛知県刈谷市住吉町3-8 コスモビル住吉4F

※JAC-Academyの座標は住所に基づく位置のため、建物の正確な入口位置とは数十m程度ずれる可能性があります。
